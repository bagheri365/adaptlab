INTERPRETATION
- When BM25 retrieves all required evidence, the canonical RAG run is close to the gold-evidence condition and slightly above Oracle on this frozen bundle, which is consistent with a small remaining generation/reasoning gap rather than a large retrieval gap.
- The extra-chunk bucket does not show a clear degradation signal relative to Oracle in the aggregate; the frozen artifacts do not establish distractor causality.
- No-gold retrieval still leaves a meaningful gap: 5/9 correct is materially below the all-required-gold condition, while evidence-ABSENT is mostly correct because that slice has no retrieval target.
- UPDATED and REMOVED do not separate cleanly into retrieval-only failures; RAG and Oracle track one another closely on the observed retrieval-conditioned subgroups, so the remaining errors are mostly shared residual behavior with a small slice-specific Oracle edge in REMOVED.

LIMITATION
- This artifact is derived only from frozen PROMPT, RAG, ORACLE_CONTEXT, benchmark, and BM25 retrieval outputs; it does not rerun inference, retrieval, scoring, normalization, or model configuration.
- The exact Oracle gold set bucket is empty after excluding behavior_only examples, so there is no nontrivial retrieval-eligible exact-match comparison in this canonical primary-test slice.
- The artifacts do not justify claims about distractor causality, dense retrieval performance, LoRA benefit, or cross-model generality.
